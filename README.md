# Electronic e-commerce store

## Description
This is the front-end side of an ecommerce site. Features account creation, login feature, item cart and checkout page.
Utilizes React and Redux Toolkit to handle states and cart organization, connect to the back-end side for proper use.

## Technologies
- React
- Redux Toolkit
- Javascript
- Styled-components
- Axios

## Features
- Log-in page
- Account creation (Axios API Endpoint)
- Store page with many products
- Cart
- Checkout page with back-end logging (Axios)

## How to run

### Front-end

1. Clone this repository:
    ```bash
   git clone https://github.com/rmadilloman/React-E-Commerce.git
    cd React-E-Commerce/ecommerce-app

2. Install dependencies:
   ```bash
   npm install

4. Start the development server:
   ```bash
   npm start

  
### back-end
1. Clone the back-end repository:
   ```bash
   git clone (https://github.com/rmadilloman/demo-full-ecommerce)

2. Install dependencies:
    ```bash
   pip install -r requirements.txt

3. Run migrations
   ```bash
    python manage.py migrate

  4. Start the server
     ```bash
     python manage.py runserver
